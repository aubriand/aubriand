Banking REST API built to explore enterprise-style backend development with **Java 21 and Spring Boot**.

**Java 21 · Spring Boot · Spring Security · PostgreSQL · Flyway · Docker**

- Stateless JWT authentication and authorization
- Customer, account, transaction and transfer management
- Modular architecture with controllers, services, repositories and DTOs
- Integration tests covering authentication and banking operations
- Development organized through small tickets and pull requests

### 📺 Quiz TV

Local multiplayer quiz where the **TV becomes the game board** and players answer from their phones.

**React · TypeScript · Fastify · Socket.io · SQLite · Drizzle ORM**

- Three synchronized interfaces: TV, players and administration
- Server-authoritative game state
- Nine game modes sharing the same game engine
- Real-time synchronization with Socket.io
- Image, audio and video questions
- Import/export and translation pipeline

### 🎥 OBS Overlay

Web platform for building custom **real-time OBS overlays** connected to game data.

**Next.js · React · TypeScript · PostgreSQL · Prisma · WebSocket**

- Visual overlay builder
- OBS Browser Source integration
- Real-time WebSocket data pipeline
- Local bridge between the game and the web application
- JWT authentication with httpOnly cookies
- User-specific overlays and event routing
